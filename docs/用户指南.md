# 用户指南

适用于 Shortcut Studio Bridge75 **ANSI NoRGB** 版，固件为本仓库构建的 `bridge75_ansi_norgb_<标签>_<时间>.bin`。其他配列或带 RGB 的版本不要刷。

## 1. 选文件

每次构建产出两个文件，**正常刷第一个**：

| 文件 | 用途 |
| --- | --- |
| `bridge75_ansi_norgb_<标签>_<时间>.bin` | 正式版（软唤醒）。从休眠醒来时保留按键和计数 |
| `bridge75_ansi_norgb_<标签>_<时间>_resetwake.bin` | 回退版。从休眠醒来时重启 MCU，可能丢首键、诊断计数清零。只在正式版醒不过来时对照用 |
| `SHA256SUMS-<标签>-<时间>` | 两个文件的校验值 |

当前推荐哪一版见 [README 的当前状态](../README.md#当前状态)。校验：

```sh
shasum -a 256 -c SHA256SUMS-<标签>-<时间>
```

## 2. 刷机

1. 拔掉 USB 线。**按住 Esc** 插入 USB，键盘进入 DFU（引导程序 `wb32-dfu`）。
2. 用 [QMK Toolbox](https://github.com/qmk/qmk_toolbox) 选择 `.bin`，点 Flash。
3. 刷完**确认已退出 DFU**：拔插一次 USB，能正常打字才算完成。留在 DFU 时键盘不能打字，这是曾经出现过的误会。
4. 在空白文本框按 **Fn+D**，松开所有键，等它逐字输出完。开头应为 `bridge75-<标签>-<时间>`，与文件名一致（文件名里标签和时间之间的 `_` 在这里是 `-`）。对不上说明没刷进去或刷错了文件。

刷入新固件后 VIA 键图会自动恢复成默认（见第 5 节）；保存的连接模式和模块休眠设置不受影响。

## 3. 键位

Fn 是右下角右 Alt 旁边的键。Windows 和 Mac 两套布局的 Fn 层完全相同。

### 连接与功能

| 按键 | 功能 |
| --- | --- |
| Fn+1 / 2 / 3 | 切到蓝牙 1 / 2 / 3。**按住 1 秒**进入配对 |
| Fn+4 | 切到 2.4G 接收器。**按住 1 秒**进入配对 |
| Fn+5 | 切到 USB 有线 |
| Fn+` | 开关模块 30 分钟休眠（保存，诊断里的 `sleep`），默认关 |
| Fn+D | 输出诊断（见[诊断与实机测试](诊断与实机测试.md)） |
| Fn+B | 输出电量 `bat=NN` |
| Fn+左下第二个键（Win 键） | 在 Windows / Mac 布局之间切换，保存 |
| Fn+Esc | 清空设置：恢复默认键图、回到 USB 模式、关闭模块休眠 |

说明：

- 短按 Fn+1–4 只切换，不会清掉已配对的主机；按住超过 1 秒才发配对命令。
- Fn+Esc 只清键盘这边的设置，**不会清除无线模块里保存的配对记录**。
- Fn+D、Fn+B 的输出**末尾没有回车**，光标停在同一行；连按两次会接在一起。

### Fn 层的 F 键

| 键 | 功能 | 键 | 功能 |
| --- | --- | --- | --- |
| F1 / F2 | 屏幕亮度 − / + | F7 / F8 / F9 | 上一首 / 播放暂停 / 下一首 |
| F3 | Mission Control | F10 | 静音 |
| F4 | Launchpad | F11 / F12 | 音量 − / + |
| F5 / F6 | F5 / F6 | | |

### 两套布局的区别

| 布局 | 左下三键 | 右下 |
| --- | --- | --- |
| Windows（默认） | Ctrl、Win、Alt | 右 Alt、Fn |
| Mac | Ctrl、Option、Command | 右 Command、Fn |

## 4. 指示灯

键盘只有 6 颗状态灯：Caps、Esc、蓝牙 1–3、2.4G（分别在 Esc、1、2、3、4 键下）。

| 情况 | 灯 |
| --- | --- |
| Caps Lock 打开 | Caps 键白色 |
| 按住 Fn | 1–4 键亮起：Windows 布局橙色，Mac 布局蓝色（可借此确认当前布局） |
| 按住 Fn 时的 Esc | 电量：充电中白、>90% 绿、>50% 蓝、>10% 黄、其余红；模块还没报电量时蓝色 |
| 无线配对中 | 当前设备的键白色快闪 |
| 无线未连接 | 当前设备的键白色慢闪（不按 Fn 也会闪） |
| 无线已连接 | 按住 Fn 时当前设备的键白色常亮 |

灯在闲置 1 分钟后熄灭；键盘进入休眠前会切断灯的供电。

## 5. 有线 VIA 改键

只在 **USB 有线模式**下可用。切到蓝牙或 2.4G 时 USB 会断开，VIA 里的键盘随之消失，这是设计如此。

1. 用 USB 线连接，按 Fn+5 切到有线（Fn+D 里 `dev=0`）。
2. 打开 <https://usevia.app> → **Design** → **Load Draft Definition**，选择仓库里的 [`docs/via/bridge75-norgb-via.json`](via/bridge75-norgb-via.json)。浏览器会记住这个定义。
3. 回到 **Configure**，选择 `Bridge75 ANSI NoRGB`，即可读写 4 层键图。
4. 自定义键位在 **Custom** 分类里，共 8 个：

   | VIA 名称 | 功能 |
   | --- | --- |
   | BT1 / BT2 / BT3 | 蓝牙 1–3（按住 1 秒配对） |
   | 2.4G | 2.4G（按住 1 秒配对） |
   | USB | 有线 |
   | DIAG | 输出诊断 |
   | BAT | 输出电量 |
   | SLEEP | 开关模块休眠 |

注意：

- 定义文件必须和固件匹配。via 版（2026-11-21 01:06 构建，11 个自定义键位）的旧定义不能用于现在的固件。
- 每次刷入新构建，VIA 的校验值会变，键图自动恢复默认；需要的话先在 VIA 里导出备份。
- VIA 列表里可能还有 `Bridge75 2.4G`：那是 2.4G 接收器自己的接口，不是键盘，配置不了。
- 定义里没有灯光菜单，状态灯由固件控制。

## 6. 休眠与续航

- 无线模式下**无按键 5 分钟**，MCU 进入休眠（STOP），按任意键唤醒，首键会正常送出。
- 插着 USB 线（不论有线还是无线模式）时不会休眠。
- 2.4G 模式下电脑睡眠时，键盘会提前进入休眠。
- Fn+` 控制的是**无线模块自己的** 30 分钟休眠，与 MCU 休眠是两回事，默认关闭。项目最初的"闲置后首键延迟或丢失"与它有关，未查明前建议保持关闭（`sleep=0`）。
- 电量每 30 秒向模块查询一次（只在无线模式）。开机后头一两秒、模块还没回报时 `bat` 显示 100。

## 7. 常见问题

| 现象 | 处理 |
| --- | --- |
| 刷完不能打字 | 多半还在 DFU，拔插 USB；仍不行就重新刷 |
| Fn+D 没有输出 | 需要松开所有键（包括 Fn）、且当前在有线或无线已连接，才会开始输出 |
| Fn+D 输出到一半停了 | 切换设备会取消输出；重按一次 |
| 蓝牙连不上 | 看对应键是否慢闪；按住 Fn+1–3 一秒重新配对，并在电脑上删除旧的配对记录 |
| 无线下 VIA 找不到键盘 | 正常，VIA 只支持有线 |
| 设置乱了 | Fn+Esc 恢复默认 |
| 怀疑新固件有问题 | 刷回上一个版本或 diag3 对照，见 [README](../README.md#当前状态) |

报告问题时请附上 Fn+D 的完整输出，最好是出问题前后各一次。
