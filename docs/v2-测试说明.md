# v2：先验证切换与状态灯

请刷 `bridge75_ansi_norgb_v2.bin`，不要混用旧的无 v2 文件。先不测试休眠。

1. 在 QMK Toolbox 中刷入后退出 DFU，正常重新插拔 USB。
2. 确认 USB 能打字。在空白英文文本编辑器按 Fn+D，松开，应该输出 `bridge75-v2 ...`。Fn 是右侧 Alt/GUI 与左方向键之间的键。
3. 按住 Fn，应有状态灯反馈（尚未读到电量时 Esc 为蓝色）。
4. 长按 Fn+1 约 1 秒，查看 1 键的蓝牙灯是否闪烁，并在电脑蓝牙设置里尝试配对 Bridge75。
5. 若没有连上，按 Fn+反引号切回 USB，再按 Fn+D，把诊断行与灯光现象反馈。
6. 1 正常后再测 Fn+2/3/4。普通短按切换，长按配对。

v2 修复：

- 保存无线模式后启动，QMK 后续 USB 初始化会覆盖无线 driver；改在主循环中恢复选择。
- 切设备会清队列，因此名称与配置改在清理之后排入，恢复后重发。
- 控制命令失败后即使没有键盘报告，也按退避尝试重连。
- 初始化/切设备恢复状态灯 renderer 和供电，避免旧 RGB disable 或 USB suspend 将灯隐藏。
- 非法持久默认层归一化，保留合法 Windows/Mac 基础层。

主机回归与编译可以验证上述代码路径；尚未证明你的无线模块在实机收到命令及成功连上。
