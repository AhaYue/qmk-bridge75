# diag3：定位模块无回复与状态灯

根据v2反馈：Fn层正常；固件尚未识别模块版本/状态，正在重试。不能仅凭fw=0判断模块损坏。

这份固件增加可验证计数，没有更换引脚或电源极性：
- rx：从UART驱动取到的字节数。
- ack：发送忙状态下识别到的正确ACK数。
- valid：校验正确的模块回复帧数；bad：完整帧校验失败数。
- tx：调用UART发送的包数（不等于证明引脚上有正确波形）。
- rgb：enable/mode/suspend；leds：状态灯渲染回调次数；rail：PB7输入读值，代码设计为0时使能灯供电，不能作为实际电压测量。

先确认键盘的无线电源开关已开启。刷bridge75_ansi_norgb_diag3.bin并退出DFU，先保持USB。等10秒，Fn+D，松开所有键，等待整行（约7秒）输出完毕。将整行贴回。无需先配对或等待休眠。

若rx=0，优先调查模块电源/串口接收；rx>0而ack/valid=0则调查协议、噪声与串口时序。leds增长但不亮需要继续区分WS2812数据、供电与硬件时序。上述均是排查分支，不是已确定的故障原因。

本机：编译/lint、UBSan协议与新计数测试、板级回归通过；无实机验证。
